## 🔴 P0 — Bu Hafta Yapılması Gerekenler

### 1. OCR'ye doğru görüntü ver (en yüksek getiri)

Şu an `batchOcrSelected` ve `quickExportFiles` içindeki OCR yolu, **`getPageFullCanvas` çıktısını olduğu gibi** Tesseract'e veriyor. Sorunlar:

- `fullCanvas` yoksa `renderPdfPageToCanvas(page, 2.0)` → ~144 DPI. **Tesseract 300 DPI sever.**
- Filtre `bw`/`ccitt` uygulanmışsa 1-bit görüntü gidiyor → LSTM için ölümcül.
- `user_defined_dpi` verilmiyor → Tesseract 70 DPI varsayıyor.

**Düzeltme — OCR için ayrı hazırlık hattı:**

```javascript
async function prepareOcrCanvas(page) {
  // 1) Kaynak: temiz (filtresiz) canvas
  let src = page.cleanFullCanvas;
  if (!src) {
    if (page.pdfPage) {
      // 300 DPI hedefi: A4 ~2480 px genişlik
      const vp = page.pdfPage.getViewport({ scale: 1.0 });
      const targetScale = Math.min(300 / 72, 2480 / vp.width);
      const { canvas } = await renderPdfPageToCanvas(page.pdfPage, targetScale);
      src = canvas;
    } else if (page.imageObj) {
      src = document.createElement('canvas');
      src.width = page.imageObj.naturalWidth;
      src.height = page.imageObj.naturalHeight;
      src.getContext('2d').drawImage(page.imageObj, 0, 0);
    } else {
      src = page.cleanThumbCanvas || page.thumbCanvas;
    }
  }

  // 2) Kenar payı: 20px beyaz çerçeve
  const PAD = 20;
  const out = document.createElement('canvas');
  out.width = src.width + PAD * 2;
  out.height = src.height + PAD * 2;
  const octx = out.getContext('2d', { willReadFrequently: true });
  octx.fillStyle = '#FFFFFF';
  octx.fillRect(0, 0, out.width, out.height);
  octx.drawImage(src, PAD, PAD);

  // 3) Hafif gri + kontrast (1-bit DEĞİL)
  const imgData = octx.getImageData(0, 0, out.width, out.height);
  const d = imgData.data;
  for (let i = 0; i < d.length; i += 4) {
    // Gri tonlama + hafif kontrast germe
    const g = 0.299 * d[i] + 0.587 * d[i+1] + 0.114 * d[i+2];
    const v = Math.min(255, Math.max(0, (g - 128) * 1.15 + 128 + 8));
    d[i] = d[i+1] = d[i+2] = v;
  }
  octx.putImageData(imgData, 0, 0);
  return out;
}
```

**Tesseract worker ayarları:**

```javascript
async function createOcrWorker(lang) {
  await loadExternalScript('https://cdn.jsdelivr.net/npm/tesseract.js@5/dist/tesseract.min.js');
  const worker = await Tesseract.createWorker(lang, 1, {
    // OEM 1 = LSTM_ONLY, langPath best için
    langPath: 'https://tessdata.projectnaptha.com/4.0.0_best',
    logger: m => { /* progress */ }
  });
  await worker.setParameters({
    tessedit_pageseg_mode: '4',          // PSM 4: tek sütun değişken
    preserve_interword_spaces: '1',
    user_defined_dpi: '300'
  });
  return worker;
}
```

**Worker'ı yeniden kullan:** Şu an `quickExportFiles` içinde her çağrıda `createWorker` + `terminate` var. Sayfa döngüsü boyunca **tek worker** kullanılmalı; `batchOcrSelected` zaten böyle ama `quickExportFiles` değil.

function releaseFullCanvases(page) {

### 4. Aranabilir PDF (Searchable PDF) — "wow effect"

`batchOcrSelected` şu an sadece `.txt` veriyor. Kullanıcıya **görünmez text layer'lı PDF** ver:

```javascript
async function buildSearchablePdf(pages, ocrResults) {
  const { PDFDocument, StandardFonts, rgb } = PDFLib;
  const doc = await PDFDocument.create();
  const font = await doc.embedFont(StandardFonts.Helvetica);

  for (let i = 0; i < pages.length; i++) {
    const p = pages[i];
    const canvas = await getPageFullCanvas(p);
    // Sayfayı JPEG olarak göm
    const imgBytes = await fetch(canvas.toDataURL('image/jpeg', 0.85)).then(r => r.arrayBuffer());
    const img = await doc.embedJpg(imgBytes);
    const pdfPage = doc.addPage([canvas.width, canvas.height]);
    pdfPage.drawImage(img, { x: 0, y: 0, width: canvas.width, height: canvas.height });

    // OCR kelime kutularını görünmez metin olarak ekle
    const words = ocrResults[i].data.words || [];
    for (const w of words) {
      const bbox = w.bbox; // {x0,y0,x1,y1} — Tesseract koordinatları
      const fontSize = Math.max(4, (bbox.y1 - bbox.y0) * 0.8);
      pdfPage.drawText(w.text, {
        x: bbox.x0,
        y: canvas.height - bbox.y1, // PDF koordinatı ters
        size: fontSize,
        font,
        color: rgb(0, 0, 0),
        opacity: 0  // görünmez ama kopyalanabilir/aranabilir
      });
    }
  }
  return await doc.save();
}
```

> Not: `opacity: 0` bazı PDF okuyucularda render edilmez ama **text extraction ve Ctrl+F çalışır**. Alternatif: `renderingMode: 3` (invisible). pdf-lib doğrudan desteklemiyorsa `drawText` opsiyonlarına bakılmalı.

### 5. PDF'de metin varsa OCR yapma

```javascript
async function pdfHasTextLayer(fileBytes) {
  const pdf = await pdfjsLib.getDocument({ data: fileBytes.slice(0) }).promise;
  const page = await pdf.getPage(1);
  const tc = await page.getTextContent();
  const totalChars = tc.items.reduce((s, it) => s + (it.str || '').length, 0);
  return totalChars > 50; // eşik
}
```

`quickExportFiles` OCR modunda: eğer PDF dijitalse `getTextContent` ile metni çek, Tesseract'i **hiç çalıştırma**.

### 6. Modal scale/koordinat kırılganlığı

`modalRenderWorkspace` içindeki `parentW` hesabı layout tamamlanmadan yapılırsa yanlış. **ResizeObserver** ile düzelt:

```javascript
let modalResizeObserver = null;

function openStudioEditor(index) {
  // ... mevcut kod ...
  const wrap = document.getElementById('modal-canvas-wrap');
  if (!modalResizeObserver && wrap) {
    modalResizeObserver = new ResizeObserver(() => {
      if (document.getElementById('studio-modal').style.display !== 'none') {
        modalRenderWorkspace();
      }
    });
    modalResizeObserver.observe(wrap.parentElement);
  }
}
```

Ayrıca pointer → canvas koordinat dönüşümünde `modalDisplayScale` yerine **her seferinde `getBoundingClientRect`** kullan (zaten kısmen yapılıyor ama `onPointerDown` içindeki `closest` hesabı CSS koordinatıyla karışık). Tutarlılık için tek bir `cssToCanvas()` yardımcısı:

```javascript
function cssToCanvas(canvas, clientX, clientY, displayScale) {
  const rect = canvas.getBoundingClientRect();
  const cssX = clientX - rect.left;
  const cssY = clientY - rect.top;
  return {
    x: (cssX / rect.width) * canvas.width,
    y: (cssY / rect.height) * canvas.height,
    cssX, cssY
  };
}
```

### 7. Warp kalitesi: 16×16 → 32×32 + homografi

Mevcut `modalProcessWarp` bilinear sampling ile 16 adım kullanıyor. Büyük açılarda artefakt. İki seçenek:

- **Hızlı:** `steps = 32` yap (maliyet 4× ama hâlâ kabul edilebilir).
- **Doğru:** OpenCV `getPerspectiveTransform` + `warpPerspective` (OpenCV zaten lazy yükleniyor):

```javascript
function warpWithOpenCV(srcCanvas, corners) {
  const src = cv.imread(srcCanvas);
  const dst = new cv.Mat();
  const srcTri = cv.matFromArray(4, 1, cv.CV_32FC2, [
    corners[0].x, corners[0].y,
    corners[1].x, corners[1].y,
    corners[2].x, corners[2].y,
    corners[3].x, corners[3].y
  ]);
  const w = Math.max(
    Math.hypot(corners[1].x - corners[0].x, corners[1].y - corners[0].y),
    Math.hypot(corners[2].x - corners[3].x, corners[2].y - corners[3].y)
  );
  const h = Math.max(
    Math.hypot(corners[3].x - corners[0].x, corners[3].y - corners[0].y),
    Math.hypot(corners[2].x - corners[1].x, corners[2].y - corners[1].y)
  );
  const dstTri = cv.matFromArray(4, 1, cv.CV_32FC2, [0,0, w,0, w,h, 0,h]);
  const M = cv.getPerspectiveTransform(srcTri, dstTri);
  cv.warpPerspective(src, dst, M, new cv.Size(w, h), cv.INTER_LINEAR, cv.BORDER_CONSTANT, new cv.Scalar(255,255,255,255));
  const out = document.createElement('canvas');
  out.width = w; out.height = h;
  cv.imshow(out, dst);
  src.delete(); dst.delete(); srcTri.delete(); dstTri.delete(); M.delete();
  return out;
}
```

### 10. Focus trap + ARIA live

```javascript
// Modal açıldığında
const modal = document.getElementById('studio-modal');
const focusable = modal.querySelectorAll('button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])');
const first = focusable[0], last = focusable[focusable.length - 1];
modal.addEventListener('keydown', (e) => {
  if (e.key !== 'Tab') return;
  if (e.shiftKey && document.activeElement === first) { e.preventDefault(); last.focus(); }
  else if (!e.shiftKey && document.activeElement === last) { e.preventDefault(); first.focus(); }
});
first.focus();
```

## 💡 Sonuç

Projenin **mühendislik kalitesi yüksek** — özellikle kendi CCITT G4 encoder'ı, non-destructive filtre mimarisi ve üç motorlu köşe tespiti ciddi iş. Asıl darboğaz **OCR hattı** ve **bellek yönetimi**.

**Tek cümlelik özet:** Belleği 4 kopyadan kurtar, OCR'ye faks değil 300 DPI gri ver, Tesseract'i `tessdata_best` + PSM 4/6 + `user_defined_dpi:300` ile kullan, ardından aranabilir PDF ekle — G4 encoder'ın zaten moat'ın.

İstersen **1. maddedeki `prepareOcrCanvas` + worker ayarlarını** doğrudan mevcut `batchOcrSelected` ve `quickExportFiles` fonksiyonlarına uygulanmış halde (tam diff) çıkarabilirim.
